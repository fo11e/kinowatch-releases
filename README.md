# Kinowatch — обновления

Публичная лента обновлений для [Sparkle](https://sparkle-project.org).

- `appcast.xml` — список версий, раздаётся через GitHub Pages:
  https://fo11e.github.io/kinowatch-releases/appcast.xml
- Архивы приложения — во вкладке **Releases** этого репозитория.

Каждый архив подписан Developer ID, заверен Apple и подписан ключом EdDSA
обновлений. Содержимое обновляет скрипт `scripts/release.sh` основного
(приватного) репозитория — вручную здесь ничего править не нужно.
